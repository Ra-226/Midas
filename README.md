# Boosting Query Recovery against Encrypted Databases: High-Accuracy and Efficient Inference Attacks Using Minimal Leakage

## Midas

This repository provides the Python 3.9 reference implementation for the paper *Boosting Query Recovery against Encrypted Databases: High-Accuracy and Efficient Inference Attacks Using Minimal Leakage*.

It includes the `Midas` attack, strong baseline implementations, preprocessed datasets, experiment drivers, cached result files, and plotting scripts used to reproduce the paper's main figures.

## Highlights

- Implements `Midas` together with `Jigsaw`, `IHOP`, `IHOP^M`, `IKK`, `SAP`, and `Score`.
- Covers the full experimental pipeline: attack execution, result serialization, and figure generation.
- Ships with ready-to-use processed statistics for both `Enron` and `Lucene`.
- Organizes experiments by ablation, parameter study, runtime comparison, and defense evaluation.

## Experimental Scenarios

The experiments use two datasets, `Enron` and `Lucene`, and three query-generation scenarios:

- `S1`: the keyword universe $\mathsf{W}$ consists of $n$ randomly selected keywords from $\mathcal{U}$, and the keywords of $m$ observed queries are uniformly distributed over $\mathsf{W}$.
- `S2`: the keyword universe $\mathsf{W}$ contains the top-$n$ most frequent keywords in $\mathcal{U}$, and the keywords of $m$ observed queries are uniformly distributed over $\mathsf{W}$.
- `S3`: the selected keyword set $\mathsf{W}$ is identical to `S2`, while the $m$ observed queries correspond to the top-$m$ most popular keywords in $\mathsf{W}$.

## Implemented Methods and Default Parameters

| Method | Default parameters |
| --- | --- |
| `IKK` | `initial temperature=200`, `cooling rate=0.999`, `termination temperature=10^-10`, `rejection threshold=1500` |
| `Score` | `RefSpeed=10` |
| `SAP` | $\alpha = 0$ |
| `IHOP` | `pfree=0.25`, `niters=1000` |
| `Jigsaw` | $\alpha = 1$, $\beta = 0.9$, `BaseRec=45`, `ConfRec=35`, `RefSpeed=10` |
| `Midas` | $\rho = 20$, $\sigma = 55$, $\eta = 1$, $\gamma = 4$, $\mu = 25$, $\delta = 10$ |
| `IHOP^M` | $\theta = 5$, `pfree=0.25`, `niters=500` |
| `CLRZ` defense | `tpr=0.999`, $\mathrm{fpr} \in [0.01, 0.02, 0.05]$ |

## Quick Start

Install dependencies:

```sh
pip3 install -r requirements.txt
```

Run a core experiment from the repository root:

```sh
python3 PRTest.py
```

Then generate the corresponding figure from the `pic/` directory:

```sh
cd pic
python3 PRaPlot.py
python3 PRbPlot.py
```

## Reproduction Workflow

1. Run an experiment script from the repository root.
2. The script writes intermediate results to `pic_pkl/`.
3. Change into `pic/` and run the matching plotting script to export the final PDF into `pic/pictures/`.

Experiment scripts assume the repository root as the working directory, while plotting scripts assume `pic/` as the working directory.

## Datasets

The repository already includes processed dataset artifacts in `Datasets/`:

- `Enron_3000.pkl`
- `Lucene_3000.pkl`
- `Lucene_6000.pkl`

These files contain the statistics used directly by the experiments, so no preprocessing is required for standard reproduction.

### Raw sources

- Enron: `https://www.cs.cmu.edu/~enron/`
- Lucene mailing list: `http://mail-archives.apache.org/mod_mbox/lucene-java-user`

Example command to mirror the Lucene archives on a Unix-like shell:

```sh
mkdir apache_ml
cd apache_ml
for y in {2002..2022}; do
    for m in {01..12}; do
        wget "http://mail-archives.apache.org/mod_mbox/lucene-java-user/${y}${m}.mbox"
    done
done
```

### Processed data format

Each dataset pickle is a list of length `4`:

1. keyword statistics over indexed documents
2. query statistics aligned with those keywords
3. non-overlapping non-indexed document lists
4. indexed document lists

For example, `"dog": [1, 2, 3]` means that the keyword or query appears in documents `1`, `2`, and `3`.
